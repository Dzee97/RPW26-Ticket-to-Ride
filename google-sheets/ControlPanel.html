Reset game

Clears all stop deposits and task and puzzle progress. Teams, config, task/puzzle definitions, Route Bonus definitions and the installed network are kept. Tickets available return to the configured starting amount.

Replace network

Upload the new-format stops.csv and line_stops.csv generated by the GeoJSON network builder. The data is validated before replacement. Deposits and task and puzzle progress reset; Route Bonus definitions stay.

The source spreadsheet must contain tabs named Stop Data and Route Data.
